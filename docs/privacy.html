おくすリズム プライバシーポリシー

制定日：2026年10月20日

「おくすリズム」（以下「本アプリ」）における利用者情報の取り扱いについて説明します。

1. 取得する情報

本アプリは、利用者が入力した次の情報を扱います。

  • お薬の名前・成分・飲む量・飲む時間・残りの数・メモ・写真
  • 服用の記録（飲んだ・スキップした日時）
  • アレルギー・副作用歴・持病などの健康情報
  • 通知時刻などの設定

2. 保存場所と外部送信

上記の情報はすべて利用者の端末内にのみ保存されます。開発者を含む第三者のサーバーへ送信することはありません。本アプリは広告・アクセス解析・トラッキングの仕組みを使用していません。

3. 利用目的

服薬の通知、服用記録の表示、飲み合わせ・飲食物の注意の表示のためにのみ利用します。

4. カメラ・写真へのアクセス

お薬の写真を登録するときに限り、利用者の許可を得てカメラまたは写真ライブラリを使用します。選択した写真は端末内にのみ保存されます。

5. 通知

服薬リマインダーは端末内で予約されるローカル通知です。通知のために外部サーバーを使用することはありません。

6. 情報の削除

アプリ内でお薬や健康情報を削除するか、本アプリを端末から削除すると、保存された情報はすべて削除されます。

7. 医療情報について

本アプリが表示する飲み合わせ・飲食物の情報は、独立行政法人 医薬品医療機器総合機構（PMDA）が公開する医療用医薬品の添付文書をもとにした参考情報です。診断・治療を目的としたものではありません。

8. お問い合わせ

GitHub Issues からご連絡ください。

9. 改定

本ポリシーを改定する場合は、このページで告知します。
